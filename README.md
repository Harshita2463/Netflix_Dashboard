# Netflix Dashboard Project

## Project Overview
This project is an interactive **Netflix Dashboard** created using **Power BI** to analyze and visualize Netflix movies and TV shows data. The dashboard provides meaningful insights into Netflix content trends, ratings, genres, release years, countries, and much more.

The project includes:
- Raw Dataset (Uncleaned Data)
- Cleaned Dataset
- Power BI Dashboard File
- Dashboard Code / Queries
- Data Cleaning Process
- Dashboard Visualizations

---

## Features
- Interactive Power BI Dashboard
- Data Cleaning & Transformation
- KPI Analysis
- Genre-Based Insights
- Country-wise Content Distribution
- Movies vs TV Shows Analysis
- Ratings Analysis

- User-Friendly Visualizations

## Data Cleaning Process

The raw Netflix dataset contained:
- Missing values
- Duplicate records
- Inconsistent formatting
- Null values in important columns

### Steps Performed
- Removed duplicate rows
- Handled missing/null values
- Standardized column formats
- Converted date columns into proper format
- Cleaned categorical values
- Removed unnecessary columns
- Prepared data for visualization

## How to Setup

Follow these steps to view and interact with the dashboard:

1. **Clone or download the repository**
   - Click on the green “Code” button and download
   - Or use:

     ```bash
     git clone https://github.com/Harshita2463/Netflix_Dashboard
     ```

2. **Open the Power BI file**
   - Launch **Power BI Desktop**
   - Open: `Netflix Dashboard.pbix`

3. **Load the dataset (if required)**
   - Ensure the dataset file (`Netflix Titles.xlsx`) is in the same folder
   - Reconnect the data source if Power BI prompts for it

4. **Refresh the data model**
   - Click on **Refresh** in Power BI to load the latest data

5. **Explore the dashboard**
   - Use filters, slicers, and visuals to analyze:
     - Content trends
     - Country distribution
     - Genre insights
     - Ratings analysis
     - Release year patterns
